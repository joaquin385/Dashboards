## 📊 Dashboard Features

### Core Visualizations (8 Total)

1. **Sales Evolution Chart** - Year-over-year comparison with trend lines
2. **Revenue Decomposition** - Price, volume, and mix impact analysis
3. **Ticket Breakdown Table** - Transaction metrics and changes
4. **Performance Heatmap** - Channel × Category growth matrix
5. **Channel Divergent Bars** - Growth comparison across channels
6. **Product Ranking Table** - Revenue leaders with market share
7. **Margin Analysis Matrix** - Scatter plot of revenue vs profitability
8. **Inventory Rotation Analysis** - Stock status and alerts

### Interactive Filters

- **Year Filter:** 2023 / 2024
- **Channel Filter:** All Channels / Online / Store 1 / Store 2
- **Category Filter:** All Categories / Electronics / Clothing / Home

### KPI Cards (5)

- Total Revenue with YoY % change
- Total Units with growth indicator
- Transaction count with change
- Gross Margin % with dollar value
- Average Ticket with units per transaction

## 📈 Sample Data Overview

**Dataset:** retail_sales_data.csv

- **Time Period:** January 2023 - December 2024 (24 months)
- **Transactions:** 145 sales transactions
- **Channels:** 3 (Online, Store 1, Store 2)
- **Categories:** 3 (Electronics, Clothing, Home)
- **Products:** 8 products with varying prices and margins
- **Metrics:** Date, units, prices, costs, stock levels per transaction

**Key Insights from Data:**
- 20.4% revenue growth (2024 vs 2023)
- Store 1 leads with 23.6% growth
- Product G is top performer ($135K revenue)
- Maintained 30% gross margin
- Inventory risks identified (Product C: low stock, Product F: excess)

## 🔧 Technical Specifications

**Technology Stack:**
- **Frontend:** Pure HTML5 + CSS3 + JavaScript (ES6+)
- **Charts:** Chart.js 4.4.0 (line, bar, bubble charts)
- **Data Parsing:** PapaParse 5.4.1 (CSV handling)
- **Dependencies:** All via CDN (no npm/build process)
- **Compatibility:** Modern browsers (Chrome, Firefox, Safari, Edge)

**File Size:**
- Dashboard HTML: ~42 KB
- CSV Data: ~11 KB
- Total Package: ~1.8 MB (including screenshots)

**Performance:**
- Instant load time (single HTML file)
- Real-time filter updates
- No server required (works offline)
- Mobile-responsive
